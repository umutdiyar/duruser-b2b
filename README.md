# DuruSer B2B Order Management Panel

DuruSer B2B is a real-time order management dashboard designed for food distribution companies that currently manage customer orders manually through WhatsApp.

The goal of the project is to digitize the order flow between customer companies and DuruSer management. Customer users can create orders from their own panel, while DuruSer administrators can track, filter and manage incoming orders from a central dashboard.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod

## Planned Features

- Role-based dashboard for customer companies and DuruSer management
- Customer-specific product lists
- Real-time order tracking
- Order filtering and status management
- Exportable order reports
- Modern responsive dashboard UI

## Project Status

This project is currently under active development.
